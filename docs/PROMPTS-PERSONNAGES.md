# Prompts Gemini — personnages-guides en pixel art

Archétypes **originaux** inspirés de la pop culture : reconnaissables au premier regard, mais jamais un personnage existant (règle de `CLAUDE.md`). Chaque prompt = fiche de style commune + description du personnage.

## Fiche de style commune (à coller au début de chaque prompt)
```
Pixel art character sprite, 64x64 pixel grid upscaled with crisp nearest-neighbor edges, no anti-aliasing, no blur.
Limited palette of 16 colors, strong dark outline, cinematic lighting, subtle rim light.
Full body, front view, centered, plain flat dark navy background (#0B1020), no text, no logo, no watermark.
Original character design, not based on any existing character, film, game or brand.
Consistent series style: chunky readable silhouette, expressive pose, one signature accessory.
```

## 1. La Hackeuse au capuchon
> Premier essai (manteau noir + lunettes sombres + pluie de code vert + main ouverte) rejeté : Gemini l'a jugé trop proche d'un personnage de film existant. Évitez cette combinaison.
```
[Fiche de style] A young hacker with a bright orange oversized hoodie, round yellow-tinted goggles pushed up on her forehead, messy curly hair, fingerless gloves, holding a glowing cyan laptop under one arm, confident smile. Background: floating translucent code windows in cyan and pink, no green rain. Palette: orange, cyan, pink, charcoal.
```

## Pour la suite (motion)
Demander ensuite à Gemini une planche de 4 images (marche, repos, geste, clin d'œil) en gardant la même description, puis les assembler en animation.

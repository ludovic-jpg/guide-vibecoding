Le mot « paramètre » vient du grec *para*, « à côté », et *metron*, « la mesure ». Un paramètre se règle à côté de l'objet principal, et en change pourtant le comportement. Le menuisier ne fabrique pas son établi à chaque commande : il le règle une fois, et gagne ensuite des heures sans y penser.

La plupart des gens ne visitent jamais les Paramètres. Je vous propose une heure pour faire le tour de l'atelier avant d'y construire quoi que ce soit, sur ma propre configuration de septembre 2026, interface en français. Les libellés bougent souvent ; je décris ce que j'ai vu à l'écran ou ce que le centre d'aide affirmait à la date où j'écris.

Tout ce que nous construirons ensuite, le site vitrine du Guide, L'Atelier et le SaaS « Audit Vibe Coding », passera par cet établi.

### Trois portes pour un même atelier

Claude s'ouvre par trois portes : le navigateur (Claude.ai), l'application de bureau (macOS et Windows) et l'application mobile. Les réglages de compte sont les mêmes partout, mais l'accès à vos fichiers locaux, à votre navigateur et, sur certaines offres, à votre ordinateur passe par l'application de bureau, qui doit rester ouverte, même quand vous parlez à Claude depuis votre téléphone (centre d'aide, septembre 2026).

À la même date, Anthropic a fusionné le « chat » et Cowork, son espace de travail agentique : Claude décide lui-même s'il répond simplement ou s'il lance une tâche en plusieurs étapes.

Installez donc l'application de bureau, même si vous travaillez surtout dans le navigateur : c'est là que se trouvent les réglages les plus sensibles.

### Général : cinq lignes qui changent tout

La rubrique Général contient le réglage qui sert le plus souvent : les instructions que Claude garde en tête dans chaque conversation. Le centre d'aide, en anglais, les appelle « Instructions for Claude » : une courte note sur qui vous êtes et comment Claude doit vous parler. Le libellé français varie selon les versions.

Elles valent pour tout le compte et restent donc générales : votre métier, votre niveau, vos exigences de franchise. Ce qui concerne un chantier ira dans les instructions d'un projet (chapitre 5). Voici celles que je recommande à un vibecodeur qui débute.

```text
Je suis [votre métier] et j'apprends à construire des applications web
avec Claude et Lovable. Je ne suis pas développeur.
- Réponds en français, vouvoie-moi, va à l'essentiel.
- Définis tout terme technique la première fois que tu l'emploies.
- Quand tu proposes du code ou une action, dis en deux phrases ce qu'elle fait
  et ce qu'elle risque.
- Si mon idée ou mon plan a un défaut, dis-le franchement, même si j'insiste.
- Distingue ce que tu sais, ce que tu supposes et ce que tu ignores.
```

Un modèle de langage prédit une suite plausible de mots (chapitre 2) ; il n'a pas, de lui-même, la politesse de dire « je ne sais pas ». On peut la lui demander.

### Compte, Confidentialité, Facturation, Utilisation

Dans Confidentialité se trouve le réglage qui détermine si vos conversations peuvent servir à améliorer les modèles d'Anthropic, nommé en anglais « Help improve Claude » ; les conversations incognito n'y servent jamais, selon le centre de confidentialité consulté en septembre 2026. Je ne vous dirai pas quoi choisir, seulement de choisir, surtout si vous travaillez sur des documents de clients.

Facturation dit ce que vous payez, Utilisation ce que vous consommez. Les limites de Claude se calculent sur des fenêtres de temps glissantes : on peut les atteindre en milieu d'après-midi et les retrouver quelques heures plus tard. Consultez Utilisation chaque semaine pendant le premier mois : derrière les jours les plus gourmands, on retrouve presque toujours une conversation interminable.

Pro : 20 $ par mois (17 $ par mois en paiement annuel). Claude Code inclus.

Max : à partir de 100 $ par mois, pour environ cinq fois l'usage de Pro ; une formule plus haute existe.

Team : 25 $ par siège et par mois (20 $ en annuel).

Prix en dollars, hors taxes, relevés sur la page de tarifs d'Anthropic en septembre 2026. Vérifiez-les avant de vous abonner : ils bougent.

Pour tout ce livre, l'offre Pro suffit.

### Capacités : ce que Claude a le droit de faire

Le réglage le plus important de Capacités s'appelle, dans le centre d'aide, « Code execution and file creation ». Activé, il permet à Claude d'exécuter du code dans un environnement isolé pour fabriquer un tableur, une présentation ou un PDF. Et, selon le centre d'aide, les compétences (nous y venons) l'exigent.

:::attention Un outil qui lit peut être trompé
Le centre d'aide le dit sans détour : Claude peut être piégé par des instructions cachées dans un fichier ou une page web qu'on lui fait lire, et envoyer à un tiers des informations présentes dans la conversation. C'est ce qu'on appelle une injection de prompt. La parade tient en trois gestes : ne pas donner à lire à Claude des documents dont vous ignorez la provenance quand la conversation contient des données sensibles, surveiller ce qu'il fait, et arrêter la tâche si quelque chose paraît étrange. Le chapitre 20 revient sur ce risque en détail.
:::

### L'application de bureau : Système, Extensions, Développeur

Ce deuxième groupe n'apparaît que dans l'application installée.

Système montre, selon le centre d'aide, le dossier où Claude range ses fichiers et la liste des « dossiers de confiance » auxquels vous lui avez donné accès, à relire de temps en temps. Extensions gère les « extensions de bureau », des serveurs MCP qui tournent sur votre ordinateur (le MCP, prise universelle entre une IA et des outils, est détaillé au chapitre 17). Développeur affiche l'état et les journaux d'erreurs de ces serveurs : vous n'y viendrez que si une extension refuse de fonctionner.

### Donner à Claude l'accès à votre ordinateur

Dans l'application de bureau, Claude peut lire et écrire dans vos dossiers locaux. Sur les offres Pro et Max, l'usage de l'ordinateur lui permet aussi de voir votre écran, de cliquer, de taper et d'ouvrir des applications.

D'après le centre d'aide, consulté en septembre 2026 :

- Claude ne peut lire et écrire que dans les dossiers que vous avez explicitement connectés.

- Pour l'usage de l'ordinateur, il demande une autorisation application par application ; certaines, comme les plateformes d'investissement et de cryptomonnaies, sont bloquées par défaut.

- Il voit tout ce qui est visible à l'écran dans ces applications, y compris des données personnelles ou des documents confidentiels.

- Il demande votre permission explicite avant de supprimer définitivement un fichier.

- Trois modes d'approbation existent : manuel, automatique avec contrôles, ou sans approbation ; ce dernier n'est à utiliser que si l'on fait entièrement confiance à tout ce qui intervient dans la tâche.

- Enfin, cette phrase, qu'il faut garder en tête : « Vous restez responsable de toutes les actions que Claude effectue en votre nom. »

Connecter votre dossier « Documents » entier, c'est donner à Claude vos factures, vos contrats, vos pièces d'identité scannées. Il ne s'en servira pas contre vous, mais un document piégé ou une instruction mal comprise (« range ce dossier ») porte sur tout ce qu'il peut atteindre.

:::mot Le privilège, une loi privée
« Privilège » vient du latin *privilegium* : *privus*, « particulier », et *lex*, « la loi ». C'est une loi faite pour un seul, une exception accordée à quelqu'un. Sous l'Ancien Régime, les privilèges étaient des droits attachés à une personne ou à une ville, et la nuit du 4 août 1789 les a abolis d'un coup.

En informatique, un privilège est un droit particulier accordé à un programme ou à une personne. Le « principe du moindre privilège » veut qu'on accorde exactement les droits nécessaires à la tâche, pas un de plus. On ne donne pas au plombier les clés de toute la maison, on lui ouvre la salle de bain. Le paradoxe : l'assistant le plus capable est celui dont il faut le plus soigneusement borner les droits, précisément parce qu'il peut beaucoup.
:::

:::fiche MOINDRE PRIVILÈGE · SÉCURITÉ
**Définition.** La règle qui consiste à n'accorder à une personne, une application ou une clé que les droits strictement nécessaires à sa tâche, sur le périmètre nécessaire, pour la durée nécessaire.

**Analogie.** Le badge d'un intervenant qui n'ouvre que l'étage où il travaille, et seulement les jours de chantier.

**À ne pas confondre avec.** La méfiance : on ne soupçonne personne, on réduit simplement ce qu'une erreur ou un vol de clé pourrait abîmer.
:::

Le centre d'aide recommande lui-même de créer un dossier de travail dédié plutôt que d'accorder un accès large, et de ne pas autoriser les applications sensibles (banque, santé, administration). Faisons-le maintenant pour le Guide.

:::notice Ouvrir un seul dossier, et le bon
1. Créez sur votre ordinateur un dossier nommé Guide-Vibe-Coding.
2. Créez dedans trois sous-dossiers du nom des futurs dépôts (chapitre 6) : guide-site, atelier, audit-vibe-coding, et un quatrième, commun, pour les documents partagés.
3. Ne mettez dans ce dossier aucun document personnel, aucune pièce d'identité, aucun fichier client, aucun mot de passe.
4. Dans l'application de bureau, connectez ce dossier, et lui seul.
5. Lisez l'avertissement affiché avant de valider, en entier.
6. Laissez le mode d'approbation sur manuel pendant les premières semaines.
7. Ouvrez la liste des dossiers de confiance dans les Paramètres et vérifiez qu'il n'y en a pas d'autres.
8. N'activez l'usage de l'ordinateur que le jour où une tâche l'exige, et fermez avant les fenêtres qui affichent des données sensibles.
:::

### Personnalisation : compétences, connecteurs, plugins

Le troisième groupe donne à Claude des savoir-faire et des accès. On s'y laisse facilement griser, car les catalogues sont bien présentés ; le moindre privilège s'y applique autant qu'aux dossiers.

**Compétences : des savoir-faire rangés dans des tiroirs**

Une compétence (en anglais *skill*) est un dossier d'instructions, parfois de scripts ou de modèles, que Claude charge quand la tâche le demande : il ne lit au départ que son nom et sa description, et n'ouvre le reste qu'au besoin. Le chapitre 27 leur est consacré ; ici, nous faisons seulement le tour du rayon.

:::planche:::

*Compétences, onglet « Les vôtres » : les compétences créées par l'utilisateur, puis celles d'Anthropic et de ses partenaires*

L'onglet « Les vôtres » liste d'abord les compétences créées ou importées par vous, puis celles « D'Anthropic et de ses partenaires ». Le bouton « Ajouter » sert à créer ou téléverser une compétence, sous forme d'un fichier ZIP selon le centre d'aide.

:::planche:::

*Compétences, onglet « Découvrir » : le catalogue, avec les boutons « Essayer » et « + » et le nombre d'installations*

L'onglet « Découvrir » est un catalogue : « Essayer » lance une conversation d'essai, « + » ajoute l'élément, et le nombre d'installations s'affiche. En septembre 2026, ce catalogue recoupait celui des plugins.

:::attention Une compétence peut exécuter du code
Le centre d'aide le répète : n'installez que des compétences de sources de confiance, et relisez les fichiers d'une compétence moins connue avant de l'activer, en particulier le code qu'elle contient et les connexions qu'elle établit. Le nombre d'installations mesure la popularité, pas la sécurité.
:::

**Connecteurs : des accès, pas des gadgets**

Un connecteur branche Claude sur un service extérieur : messagerie, agenda, fichiers en ligne, gestion de projet. Techniquement, c'est un serveur MCP distant (chapitre 17) ; pratiquement, une délégation : vous autorisez Claude à lire, et parfois à écrire, dans un outil qui contient vos données.

:::planche:::

*La barre d'outils de la rubrique Connecteurs : « Les vôtres », « Découvrir », la recherche et le bouton « Ajouter »*

:::planche:::

*Connecteurs, onglet « Découvrir » : les connecteurs les plus utilisés, cochés quand ils sont actifs*

La rubrique reprend la même structure : « Les vôtres », « Découvrir », une recherche, un bouton « Ajouter ». Sur ma capture, les connecteurs que j'ai activés sont cochés, les autres portent un « + », et chaque carte indique qui publie le connecteur (« par Google », « par Anthropic »).

Selon le centre d'aide, les connecteurs personnalisés (où l'on saisit l'adresse d'un serveur MCP) sont réservés aux offres payantes ; on active chaque connecteur conversation par conversation, avec le bouton « + » sous le champ de saisie ; et il faut lire les permissions demandées à la connexion : envoyer des e-mails en votre nom n'est pas la même chose que les lire.

:::fiche CONNECTEUR · OUTIL
**Définition.** Une liaison autorisée entre Claude et un service extérieur (messagerie, agenda, fichiers en ligne), qui lui permet d'y lire et parfois d'y agir en votre nom.

**Analogie.** Une procuration signée à la banque : utile pour qu'un proche fasse vos virements, dangereuse si elle couvre plus de comptes que nécessaire.

**À ne pas confondre avec.** Une compétence, qui apporte un savoir-faire sans donner accès à aucune donnée.
:::

Pour le Guide, un seul connecteur suffit au départ : l'espace en ligne où vous rangerez vos brouillons, si vous en utilisez un. Un connecteur inutile ouvert en permanence ajoute du contexte et une surface d'attaque.

**Plugins : la caisse à outils complète**

Un plugin regroupe des compétences, des connecteurs MCP, des commandes que l'on déclenche en tapant /, et des sous-agents, assistants spécialisés qui travaillent en parallèle. Nés dans Claude Code, ils ont gagné l'application de bureau.

:::planche:::

*Plugins, onglet « Découvrir » : les plugins d'Anthropic (Data, Design, Marketing, Finance, Product Management, Operations...)*

:::fiche PLUGIN · OUTIL
**Définition.** Un paquet installable qui réunit des compétences, des connecteurs, des commandes et des sous-agents autour d'un métier ou d'une tâche.

**Analogie.** La mallette complète de l'électricien, avec ses outils, ses notices et ses câbles, par opposition à un tournevis acheté seul.

**À ne pas confondre avec.** Une extension de bureau, qui n'est qu'un serveur MCP local ; le plugin peut en contenir une, mais aussi bien d'autres choses.
:::

La documentation de Claude Code prévient que les plugins peuvent exécuter du code arbitraire sur votre machine avec vos droits. Un plugin, c'est une série d'autorisations d'un coup : installez-le pour un besoin identifié, pas pour son classement.

### Appliqué au Guide : l'atelier du jour 1

Le livre, son site, L'Atelier et le SaaS « Audit Vibe Coding » partageront le même compte Claude, celui que nous venons de préparer. Ce qui distinguera les chantiers, ce seront les projets du chapitre 5.

:::checklist L'atelier réglé pour le Guide
☐  Application de bureau installée et connectée à votre compte

☐  Instructions générales rédigées dans Général (cinq lignes, pas plus de dix)

☐  Choix fait, en connaissance de cause, dans Confidentialité

☐  Offre choisie ; Utilisation consultée une première fois

☐  Exécution de code et création de fichiers activées dans Capacités

☐  Un seul dossier connecté, Guide-Vibe-Coding, sans aucune donnée personnelle

☐  Mode d'approbation manuel

☐  Aucune extension, aucun plugin installé sans besoin identifié

☐  Au plus un connecteur actif, celui de vos brouillons

☐  Aucune clé API créée pour l'instant
:::

Je n'installe rien d'autre au départ : chaque chapitre ajoutera ce dont il montre l'usage.

:::bref Les Paramètres se règlent une fois, en une heure, avant de construire : c'est l'établi de tout le livre.
Les instructions de la rubrique Général valent pour toutes les conversations ; elles disent qui vous êtes et comment Claude doit vous répondre.

L'exécution de code (Capacités) est nécessaire pour que les compétences fonctionnent.

Donner à Claude l'accès à l'ordinateur engage votre responsabilité : un dossier dédié, sans données personnelles, en mode d'approbation manuel.

Compétences, connecteurs et plugins s'ajoutent un par un, pour un besoin identifié, selon le principe du moindre privilège.
:::
